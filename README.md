# C++ Basics

This repository contains my C++ learning journey. It includes programs and exercises covering fundamental concepts, written while building a strong foundation for Data Structures & Algorithms, Competitive Programming, and Software Development.

## Topics Covered

- Basic Maths 
- Variables & Data Types
- Input / Output
- Operators
- Conditional Statements
- Loops
- Functions
- Arrays
- Characterized Array
- Strings
- Dynamic memory
- Recursion


## How to Run

```bash
g++ filename.cpp -o program
./program
```

## Purpose

The goal of this repository is to build a strong understanding of modern C++ before moving on to advanced Data Structures, Algorithms, and Competitive Programming.
